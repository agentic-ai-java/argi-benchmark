# agentic-spring-ai 本地性能基准报告

最后验证日期：2026-09-03（Asia/Shanghai）

## 前置说明

- 本报告只评价 `agentic-spring-ai` 的 Graph 与 ReAct 框架开销。LangChain4j、Google ADK Java 只用于借鉴基准组织方式，没有运行它们的代码，也没有做跨框架排名。
- 当前会话没有 Sequential Thinking、Context7、Fetch 与 `update_plan`，调研降级为本地源码检索、公开仓库只读信息和 JMH 原始数据。影响仅限证据采集路径；回滚方式是删除本仓库新增内容，上游源码没有修改。
- 首轮 ReAct quick 测量发现默认 checkpoint thread 会累积历史，造成工作量随迭代增长；正式口径改为每次调用后释放 thread。直线图基线也从可被 JIT 折叠的整数循环改为同等 Map 状态更新链。

## 结论

在本机完整 JMH 配置下，预编译直线图的平均调用耗时从 1 节点的 `6.865 us/op` 增长到 50 节点的 `98.066 us/op`。10 到 50 节点区间的边际成本约为 `1.869 us/节点`、`11.6 KB/节点`，时间和分配量均近似线性增长。

条件循环从 10 次的 `24.250 us/op` 增长到 1000 次的 `1,947.228 us/op`，100 到 1000 次区间约为 `1.955 us/迭代`。这与直线图边际成本接近，说明当前纯内存微负载下，主要成本随节点调度次数增长。

2/8/32 个极轻节点的并行扇出分别为 `27.219 / 42.387 / 116.998 us/op`。由于节点没有可并行化的真实 CPU 或 I/O 工作量，这组数据只表示并行调度底噪；不能据此判断实际业务并行收益。

单节点启用并在调用后释放 `MemorySaver` 为 `10.003 us/op`、`59,693 B/op`；相对无 checkpoint 单节点图增加约 `3.137 us/op`（`45.7%`）和 `18.9 KB/op`（`46.2%`）。

ReAct 的确定性单模型回合为 `96.330 us/op`、`383,238 B/op`；一次本地工具往返为 `435.918 us/op`、`1,216,780 B/op`。工具往返包含模型调用、工具分派和第二次模型调用，耗时约为单模型回合的 `4.53 倍`。这些数字不包含网络和真实 LLM 推理。

模型直调基线只用于确认确定性替身的成本接近零。真实应用中 LLM 推理通常会主导端到端延迟，不应把微基准倍数直接外推到线上响应时间。

## 方法来源与数据定位

- LangChain4j 性能问题 [#4322](https://github.com/langchain4j/langchain4j/issues/4322) 使用 JMH、多档规模、同机基线和统一单位；对应 [PR #4323](https://github.com/langchain4j/langchain4j/pull/4323) 将 benchmark 作为优化证据。本项目只借鉴这些方法。
- Google ADK Java 的测试使用确定性 `TestLlm` 隔离真实模型，本项目据此使用固定响应 `ChatModel`，但不运行 ADK benchmark。
- 完整原始数据：`results/20260903T141000Z/graph/jmh.json` 与 `results/20260903T141000Z/react/jmh.json`。
- 环境快照：`results/20260903T141000Z/environment.txt`；汇总：`results/20260903T141000Z/summary.md`。
- 调研证据与固定版本：`docs/evidence.csv`；完整测试设计：`docs/benchmark-design.md`。

## 验证与限制

- `mvn -B verify` 通过；Graph smoke tests 2 个、ReAct smoke test 1 个，合计 3/3 通过。
- full JMH 结果数量为 Graph 16 项、ReAct 3 项；所有项都有主指标和 `gc.alloc.rate.norm`，没有 benchmark 异常。
- Shade 构建报告依赖 JAR 中存在重复许可证、模块描述和 Spring 资源；可执行 JAR 与所有 JMH forks 均成功运行，未发现类冲突症状。
- 本轮没有运行真实模型、远程工具、吞吐并发、长对话容量或 CPU/IO 型并行收益测试；这些应作为独立 workload，不能与本次固定工作量微基准混合。
